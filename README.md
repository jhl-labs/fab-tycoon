# Fab Tycoon

**Fab Tycoon**은 반도체 팹(Fab)을 건설하고 운영하는 경영 시뮬레이션 게임입니다.

## 게임 소개

Logic, DRAM, NAND, GaN, Photonics, Quantum 6종 팹을 건설하고, 설비 투자, 28종 인력 채용, R&D, 주문 관리를 통해 세계 최고의 반도체 기업으로 성장하세요.

### 주요 기능

- **멀티팹 경영** — 6종 팹을 동시에 운영하며 팹별 수익/비용 추적
- **실시간 3D 시뮬레이션** — 설비, 로봇, 28종 직원이 실시간으로 움직이는 팹 내부 (오피스 인테리어 포함)
- **경영 대시보드** — 재무, 생산, 설비, 시장 등 8개 탭의 종합 경영 분석 + 팹별 비교
- **HR 어드바이저** — 인력 상황 분석, 채용/복지/교육 권고, 이직 위험 감시
- **R&D 테크트리** — 공정 노드 미세화부터 AI/양자 기술까지 88종 연구
- **주문 시스템** — 고객 신뢰도 기반 주문 관리, 우선순위 분석
- **ESG 경영** — 환경, 사회, 지배구조 지표 관리
- **다중 저장 슬롯** — 자동저장 + 수동 슬롯 3개
