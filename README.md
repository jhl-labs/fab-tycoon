# Fab Tycoon

**Fab Tycoon**은 반도체 팹(Fab)을 건설하고 운영하는 경영 시뮬레이션 게임입니다.

## 게임 소개

Logic, DRAM, NAND, GaN, Photonics, Quantum 6종 팹을 건설하고, 설비 투자, 28종 인력 채용, R&D, 주문/재고/판매 전략 관리를 통해 세계 최고의 반도체 기업으로 성장하세요.

### 주요 기능

- **멀티팹 경영** — 6종 팹을 동시에 운영하며 팹별 수익/비용 추적
- **실시간 3D 시뮬레이션** — 설비, 로봇, 28종 직원이 실시간으로 움직이는 팹 내부 (오피스 인테리어 포함)
- **경영 레이어 2종** — 9개 탭 관리 패널(개요/판매 포함) + 8개 탭 대시보드로 운영 판단을 분리
- **HR 어드바이저** — 인력 상황 분석, 채용/복지/교육 권고, 이직 위험 감시
- **R&D 테크트리** — 공정 노드 미세화부터 AI/양자 기술까지 88종 연구
- **주문/판매 시스템** — 고객 신뢰도 기반 주문 관리 + 레시피별 판매 전략 + 시장 이벤트 대응
- **동적 ESG/품질** — 시대와 팹 규모에 따라 요구치가 올라가고, 압력을 방치하면 벌금/비용이 커짐
- **브랜드 압력** — 마케팅 공백과 품질/납기 사고가 브랜드 감쇠에 직접 반영
- **다중 저장 슬롯** — 자동저장 + 수동 슬롯 3개
