# Fab Tycoon

**Fab Tycoon**은 반도체 팹(Fab)을 건설하고 운영하는 경영 시뮬레이션 게임입니다.

## 게임 소개

Logic, DRAM, NAND, Photonics, Quantum 등 다양한 팹을 건설하고, 설비 투자, 인력 채용, R&D, 주문 관리를 통해 세계 최고의 반도체 기업으로 성장하세요.

### 주요 기능

- **멀티팹 경영** — 여러 종류의 팹을 동시에 운영
- **실시간 3D 시뮬레이션** — 설비, 로봇, 직원이 실시간으로 움직이는 팹 내부
- **경영 대시보드** — 재무, 생산, 설비, 시장 등 8개 탭의 종합 경영 분석
- **R&D 테크트리** — 공정 노드 미세화부터 AI/양자 기술까지
- **주문 시스템** — 고객 신뢰도 기반 주문 관리
- **ESG 경영** — 환경, 사회, 지배구조 지표 관리
